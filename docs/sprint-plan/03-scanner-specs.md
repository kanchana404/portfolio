### [SCAN-01] OpenCV.js loader: worker-hosted, progress-tracked, Cache Storage–backed

**Estimate:** 4h · **Depends on:** — · **Files:**
`public/vendor/opencv/4.10.0/opencv.js`, `public/vendor/opencv/4.10.0/opencv_js.wasm`,
`scripts/opencv-size.mjs`, `src/lib/scanner/opencv-loader.ts`, `next.config.mjs`

**Why** — OpenCV.js is ~9 MB. If it touches the initial bundle, LCP on the tool page is dead and Sprint 1's Lighthouse budget goes with it. Three rules follow: it never loads until the user commits to scanning; it loads inside a Worker so the multi-hundred-millisecond emscripten instantiation never blocks paint or input; and it lands in Cache Storage so the second visit is free. The progress bar is not decoration — 9 MB on a Sri Lankan mobile connection is 20–40 seconds, and a spinner for 30 seconds reads as "broken".

**Implementation**

First, make Vercel cache it properly. Files in `public/` are served with `cache-control: public, max-age=0, must-revalidate` by default, which defeats the point of a versioned path.

The loader itself runs **inside the worker** (`caches` is available on `WorkerGlobalScope`), so the 9 MB never crosses the main thread.

```ts
// src/lib/scanner/opencv-loader.ts
/// <reference lib="webworker" />
import { OPENCV_JS_BYTES, OPENCV_WASM_BYTES } from "./opencv-size";

const VERSION = "4.10.0";
const BASE = `/vendor/opencv/${VERSION}`;
const CACHE_NAME = `opencv-${VERSION}`;

type ProgressFn = (fraction: number) => void;

/** Fetch a URL, streaming progress, storing the result in Cache Storage. */
async function cachedBlob(
  url: string,
  expectedBytes: number,
  onBytes: (delta: number) => void,
): Promise<Blob> {
  const cache = await caches.open(CACHE_NAME);
  const hit = await cache.match(url);
  if (hit) {
    onBytes(expectedBytes); // already local: count it as instantly complete
    return hit.blob();
  }

  const res = await fetch(url);
  if (!res.ok || !res.body) {
    throw new Error(`Failed to fetch ${url}: ${res.status}`);
  }

  const reader = res.body.getReader();
  const chunks: Uint8Array[] = [];
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    chunks.push(value);
    onBytes(value.byteLength);
  }

  const blob = new Blob(chunks as BlobPart[]);
  // Storing a fresh Response keeps the cache independent of HTTP heuristics.
  await cache.put(url, new Response(blob));
  return blob;
}

/** Evict caches from older OpenCV versions so we don't accumulate 9 MB per upgrade. */
async function evictOldVersions(): Promise<void> {
  const keys = await caches.keys();
  await Promise.all(
    keys.filter((k) => k.startsWith("opencv-") && k !== CACHE_NAME).map((k) => caches.delete(k)),
  );
}

let readyPromise: Promise<any> | null = null;

/**
 * Loads OpenCV.js into this worker and resolves with the `cv` namespace.
 * Idempotent: repeated calls return the same promise.
 */
export function loadOpenCv(onProgress: ProgressFn): Promise<any> {
  if (readyPromise) return readyPromise;

  readyPromise = (async () => {
    await evictOldVersions();

    const total = OPENCV_JS_BYTES + OPENCV_WASM_BYTES;
    let seen = 0;
    const bump = (delta: number) => {
      seen += delta;
      // Clamp: transfer-encoding differences can overshoot the byte estimate.
      onProgress(Math.min(0.99, seen / total));
    };

    // Both artifacts are fetched by us, not by emscripten, so both are on the bar.
    const [jsBlob, wasmBlob] = await Promise.all([
      cachedBlob(`${BASE}/opencv.js`, OPENCV_JS_BYTES, bump),
      cachedBlob(`${BASE}/opencv_js.wasm`, OPENCV_WASM_BYTES, bump),
    ]);

    const wasmUrl = URL.createObjectURL(wasmBlob);
    const jsUrl = URL.createObjectURL(new Blob([jsBlob], { type: "text/javascript" }));

    // MUST be set before importScripts: emscripten reads Module.locateFile during init.
    // Cache Storage is not transparent to fetch(), so we hand it a blob: URL directly.
    (self as any).Module = {
      locateFile: (path: string) => (path.endsWith(".wasm") ? wasmUrl : `${BASE}/${path}`),
    };

    (self as any).importScripts(jsUrl);
    URL.revokeObjectURL(jsUrl);

    // OpenCV >= 4.7 ships `cv` as a module factory returning a promise.
    // Older builds expose the namespace directly with an onRuntimeInitialized hook.
    let mod = (self as any).cv;
    if (typeof mod === "function") {
      mod = await mod();
    } else if (!mod?.Mat) {
      await new Promise<void>((resolve) => {
        mod.onRuntimeInitialized = () => resolve();
      });
    }
    (self as any).cv = mod;

    URL.revokeObjectURL(wasmUrl);
    onProgress(1);
    return mod;
  })();

  return readyPromise;
}
```

### [SCAN-02] Detection and warp pipeline in a worker, with hard Mat lifetime discipline

**Estimate:** 6h · **Depends on:** SCAN-01 · **Files:**
`src/lib/scanner/mat-scope.ts`, `src/lib/scanner/geometry.ts`, `src/workers/scanner.worker.ts`, `src/lib/scanner/types.ts`, `src/lib/scanner/client.ts`, `src/lib/scanner/geometry.test.ts`

**Why** — This is the whole tool. OpenCV.js is emscripten-backed: every `cv.Mat` is a handle into the WASM heap, JavaScript GC knows nothing about it, and **anything you do not `.delete()` leaks until the tab dies**. A scanner is used on ten pages in a row; a 12 MP photo is ~48 MB as RGBA. Leak three Mats per page and you OOM the tab on page five. The mitigation is not "remember to call delete" — it is a scope object plus `try/finally`, so forgetting is structurally hard.

**Implementation**

```ts
// src/lib/scanner/mat-scope.ts
interface Deletable {
  delete(): void;
}

/**
 * OpenCV.js allocates into the WASM heap; JS GC will not reclaim it.
 * Every Mat / MatVector / CLAHE goes through `add()`, and `release()` runs in a
 * finally block. Deletion is LIFO to mirror allocation order.
 */
export class MatScope {
  private items: Deletable[] = [];

  add<T extends Deletable>(m: T): T {
    this.items.push(m);
    return m;
  }

  release(): void {
    for (let i = this.items.length - 1; i >= 0; i--) {
      try {
        this.items[i].delete();
      } catch {
        // Already deleted or the runtime is torn down; never let cleanup throw.
      }
    }
    this.items.length = 0;
  }
}
```

```ts
// src/lib/scanner/geometry.ts
import type { Point, Quad } from "./types";

export function distance(a: Point, b: Point): number {
  return Math.hypot(a.x - b.x, a.y - b.y);
}

/**
 * Canonical ordering. The top-left corner has the smallest x+y, the
 * bottom-right the largest; the top-right has the smallest y-x, the
 * bottom-left the largest. Holds for any convex quad that is not rotated
 * past ~45 degrees, which is the only case a document scanner needs.
 */
export function orderCorners(pts: Point[]): Quad {
  if (pts.length !== 4) throw new Error(`orderCorners expects 4 points, got ${pts.length}`);
  const bySum = [...pts].sort((a, b) => a.x + a.y - (b.x + b.y));
  const byDiff = [...pts].sort((a, b) => a.y - a.x - (b.y - b.x));
  return [bySum[0], byDiff[0], bySum[3], byDiff[3]];
}

/** Rejects bow-ties and self-intersecting drags from the manual corner UI. */
export function isConvexQuad(q: Quad): boolean {
  let sign = 0;
  for (let i = 0; i < 4; i++) {
    const a = q[i];
    const b = q[(i + 1) % 4];
    const c = q[(i + 2) % 4];
    const cross = (b.x - a.x) * (c.y - b.y) - (b.y - a.y) * (c.x - b.x);
    if (cross === 0) continue;
    const s = Math.sign(cross);
    if (sign === 0) sign = s;
    else if (s !== sign) return false;
  }
  return true;
}

export function quadArea(q: Quad): number {
  let sum = 0;
  for (let i = 0; i < 4; i++) {
    const a = q[i];
    const b = q[(i + 1) % 4];
    sum += a.x * b.y - b.x * a.y;
  }
  return Math.abs(sum) / 2;
}

/** Output canvas size: the longest opposing edge pair, so nothing is squashed. */
export function outputSize(q: Quad): { width: number; height: number } {
  const [tl, tr, br, bl] = q;
  const width = Math.round(Math.max(distance(br, bl), distance(tr, tl)));
  const height = Math.round(Math.max(distance(tr, br), distance(tl, bl)));
  return { width: Math.max(1, width), height: Math.max(1, height) };
}

export function scaleQuad(q: Quad, factor: number): Quad {
  return q.map((p) => ({ x: p.x * factor, y: p.y * factor })) as Quad;
}

export function insetQuad(width: number, height: number, inset = 0.08): Quad {
  const dx = width * inset;
  const dy = height * inset;
  return [
    { x: dx, y: dy },
    { x: width - dx, y: dy },
    { x: width - dx, y: height - dy },
    { x: dx, y: height - dy },
  ];
}
```

The worker. Note the two things that bite everyone: `contours.get(i)` returns a **new** Mat wrapper that must be deleted on every iteration, and detection runs on a downscaled copy (a 12 MP `findContours` is ~2s; at 1024px it is ~40ms) with the corners scaled back up before the warp.

```ts
// src/workers/scanner.worker.ts
/// <reference lib="webworker" />
import { loadOpenCv } from "@/lib/scanner/opencv-loader";
import { MatScope } from "@/lib/scanner/mat-scope";
import { orderCorners, isConvexQuad, quadArea, outputSize, scaleQuad } from "@/lib/scanner/geometry";
import type { Point, Quad, ScanRequest, ScanResponse, OutputMode } from "@/lib/scanner/types";

declare const self: DedicatedWorkerGlobalScope;

const DETECT_MAX_DIM = 1024;

function post(msg: ScanResponse, transfer: Transferable[] = []): void {
  self.postMessage(msg, transfer);
}

function toMat(cv: any, bitmap: ImageBitmap, maxDim?: number): { mat: any; scale: number } {
  const scale = maxDim ? Math.min(1, maxDim / Math.max(bitmap.width, bitmap.height)) : 1;
  const w = Math.round(bitmap.width * scale);
  const h = Math.round(bitmap.height * scale);
  const canvas = new OffscreenCanvas(w, h);
  const ctx = canvas.getContext("2d", { willReadFrequently: true })!;
  ctx.drawImage(bitmap, 0, 0, w, h);
  return { mat: cv.matFromImageData(ctx.getImageData(0, 0, w, h)), scale };
}

/**
 * grayscale -> blur -> Canny -> close -> findContours -> largest valid quad.
 * Returns coordinates in FULL-RESOLUTION space, or null if nothing convincing.
 */
function detectQuad(cv: any, bitmap: ImageBitmap): Quad | null {
  const scope = new MatScope();
  try {
    const { mat: src, scale } = toMat(cv, bitmap, DETECT_MAX_DIM);
    scope.add(src);

    const gray = scope.add(new cv.Mat());
    cv.cvtColor(src, gray, cv.COLOR_RGBA2GRAY);

    const blurred = scope.add(new cv.Mat());
    cv.GaussianBlur(gray, blurred, new cv.Size(5, 5), 0, 0, cv.BORDER_DEFAULT);

    const edges = scope.add(new cv.Mat());
    cv.Canny(blurred, edges, 75, 200, 3, false);

    // Paper edges break up under uneven lighting; closing rejoins them so the
    // contour is a loop rather than four disconnected arcs.
    const kernel = scope.add(cv.getStructuringElement(cv.MORPH_RECT, new cv.Size(5, 5)));
    const closed = scope.add(new cv.Mat());
    cv.morphologyEx(edges, closed, cv.MORPH_CLOSE, kernel);

    const contours = scope.add(new cv.MatVector());
    const hierarchy = scope.add(new cv.Mat());
    cv.findContours(closed, contours, hierarchy, cv.RETR_LIST, cv.CHAIN_APPROX_SIMPLE);

    const frameArea = src.cols * src.rows;
    let best: Quad | null = null;
    let bestArea = frameArea * 0.2; // a document smaller than 20% of frame is noise

    for (let i = 0; i < contours.size(); i++) {
      // Every get() allocates a wrapper. Delete it or leak one Mat per contour.
      const contour = contours.get(i);
      const approx = new cv.Mat();
      try {
        const peri = cv.arcLength(contour, true);
        cv.approxPolyDP(contour, approx, 0.02 * peri, true);
        if (approx.rows !== 4) continue;

        const pts: Point[] = [];
        for (let r = 0; r < 4; r++) {
          pts.push({ x: approx.intAt(r, 0), y: approx.intAt(r, 1) });
        }
        const quad = orderCorners(pts);
        if (!isConvexQuad(quad)) continue;

        const area = quadArea(quad);
        if (area > bestArea) {
          bestArea = area;
          best = quad;
        }
      } finally {
        approx.delete();
        contour.delete();
      }
    }

    return best ? scaleQuad(best, 1 / scale) : null;
  } finally {
    scope.release();
  }
}

function warp(cv: any, bitmap: ImageBitmap, corners: Quad, mode: OutputMode): ImageBitmap {
  const scope = new MatScope();
  try {
    const { mat: src } = toMat(cv, bitmap);
    scope.add(src);

    const { width, height } = outputSize(corners);
    const flat = corners.flatMap((p) => [p.x, p.y]);
    const srcTri = scope.add(cv.matFromArray(4, 1, cv.CV_32FC2, flat));
    const dstTri = scope.add(
      cv.matFromArray(4, 1, cv.CV_32FC2, [0, 0, width, 0, width, height, 0, height]),
    );

    const M = scope.add(cv.getPerspectiveTransform(srcTri, dstTri));
    const warped = scope.add(new cv.Mat());
    cv.warpPerspective(
      src,
      warped,
      M,
      new cv.Size(width, height),
      cv.INTER_LINEAR,
      cv.BORDER_CONSTANT,
      new cv.Scalar(255, 255, 255, 255),
    );

    let out = warped;
    if (mode !== "color") {
      const gray = scope.add(new cv.Mat());
      cv.cvtColor(warped, gray, cv.COLOR_RGBA2GRAY);

      if (mode === "grayscale") {
        // CLAHE evens out the shadow a phone casts across the left half of a page.
        const clahe = scope.add(new cv.CLAHE(2.0, new cv.Size(8, 8)));
        const eq = scope.add(new cv.Mat());
        clahe.apply(gray, eq);
        out = scope.add(new cv.Mat());
        cv.cvtColor(eq, out, cv.COLOR_GRAY2RGBA);
      } else {
        // blockSize must be odd. 25/10 is tuned for ~1600px-wide phone captures:
        // smaller blocks eat thin strokes, larger ones leave shadow gradients.
        const bw = scope.add(new cv.Mat());
        cv.adaptiveThreshold(
          gray,
          bw,
          255,
          cv.ADAPTIVE_THRESH_GAUSSIAN_C,
          cv.THRESH_BINARY,
          25,
          10,
        );
        out = scope.add(new cv.Mat());
        cv.cvtColor(bw, out, cv.COLOR_GRAY2RGBA);
      }
    }

    const canvas = new OffscreenCanvas(out.cols, out.rows);
    const ctx = canvas.getContext("2d")!;
    ctx.putImageData(new ImageData(new Uint8ClampedArray(out.data), out.cols, out.rows), 0, 0);
    return canvas.transferToImageBitmap();
  } finally {
    scope.release();
  }
}

let cv: any = null;

self.onmessage = async (e: MessageEvent<ScanRequest>) => {
  const msg = e.data;
  try {
    if (msg.type === "init") {
      cv = await loadOpenCv((fraction) => post({ type: "progress", fraction }));
      post({ type: "ready" });
      return;
    }
    if (!cv) throw new Error("Scanner received work before init completed");

    if (msg.type === "detect") {
      const corners = detectQuad(cv, msg.bitmap);
      post({
        type: "detected",
        id: msg.id,
        corners,
        width: msg.bitmap.width,
        height: msg.bitmap.height,
      });
      msg.bitmap.close();
      return;
    }

    if (msg.type === "warp") {
      const bitmap = warp(cv, msg.bitmap, msg.corners, msg.mode);
      msg.bitmap.close();
      post({ type: "warped", id: msg.id, bitmap }, [bitmap]);
    }
  } catch (err) {
    post({
      type: "error",
      id: "id" in msg ? msg.id : undefined,
      message: err instanceof Error ? err.message : String(err),
    });
  }
};
```

Main-thread client. **The worker is terminated on unmount** — that is the only way to hand the WASM heap back to the OS, since emscripten's heap grows and never shrinks.

```ts
// src/lib/scanner/client.ts
import type { Quad, OutputMode, ScanRequest, ScanResponse } from "./types";

type Pending = { resolve: (v: any) => void; reject: (e: Error) => void };

export class ScannerClient {
  private worker: Worker;
  private pending = new Map<string, Pending>();
  private seq = 0;
  private readyResolve?: () => void;
  private ready: Promise<void>;

  constructor(onProgress: (fraction: number) => void) {
    this.worker = new Worker(new URL("../../workers/scanner.worker.ts", import.meta.url));
    this.ready = new Promise<void>((resolve) => {
      this.readyResolve = resolve;
    });

    this.worker.onmessage = (e: MessageEvent<ScanResponse>) => {
      const msg = e.data;
      if (msg.type === "progress") return onProgress(msg.fraction);
      if (msg.type === "ready") return this.readyResolve?.();
      if (msg.type === "error") {
        const p = msg.id ? this.pending.get(msg.id) : undefined;
        if (p) {
          this.pending.delete(msg.id!);
          p.reject(new Error(msg.message));
        }
        return;
      }
      const p = this.pending.get(msg.id);
      if (!p) return;
      this.pending.delete(msg.id);
      p.resolve(msg);
    };

    this.post({ type: "init" });
  }

  private post(msg: ScanRequest, transfer: Transferable[] = []): void {
    this.worker.postMessage(msg, transfer);
  }

  private call<T>(build: (id: string) => [ScanRequest, Transferable[]]): Promise<T> {
    const id = `r${this.seq++}`;
    const [msg, transfer] = build(id);
    return new Promise<T>((resolve, reject) => {
      this.pending.set(id, { resolve, reject });
      this.post(msg, transfer);
    });
  }

  async detect(bitmap: ImageBitmap): Promise<{ corners: Quad | null; width: number; height: number }> {
    await this.ready;
    return this.call((id) => [{ type: "detect", id, bitmap }, [bitmap]]);
  }

  async warp(bitmap: ImageBitmap, corners: Quad, mode: OutputMode): Promise<ImageBitmap> {
    await this.ready;
    const res = await this.call<{ bitmap: ImageBitmap }>((id) => [
      { type: "warp", id, bitmap, corners, mode },
      [bitmap],
    ]);
    return res.bitmap;
  }

  /** Only way to return the emscripten heap to the OS. Call from useEffect cleanup. */
  destroy(): void {
    this.worker.terminate();
    this.pending.clear();
  }
}
```

### [SCAN-03] Manual corner adjustment UI (the thing that makes it a product)

**Estimate:** 5h · **Depends on:** SCAN-02 · **Files:**
`src/components/tools/document-scanner/CornerEditor.tsx`, `src/components/tools/document-scanner/Loupe.tsx`, `src/components/tools/document-scanner/corner-editor.module.css`

**Why** — Auto-detection fails on a white page against a white desk, on a document that runs off the frame edge, on glare, and on anything photographed by a person in a hurry. Every scanner app that people actually keep has draggable corners. The design rule: **auto-detect seeds the handles, it never commits.** The user always lands on the editor with four handles already positioned — either from detection or at an 8% inset — so "fix it" is one drag, not a mode switch after a failure.

The second non-obvious thing: on a phone, the corner you are dragging is under your fingertip. Without a magnifier you are placing it blind. The loupe is not polish; it is the feature.

**Implementation**

```tsx
// src/components/tools/document-scanner/CornerEditor.tsx
"use client";

import { useCallback, useEffect, useRef, useState } from "react";
import type { Point, Quad } from "@/lib/scanner/types";
import { isConvexQuad } from "@/lib/scanner/geometry";
import { Loupe } from "./Loupe";

const LABELS = ["Top-left corner", "Top-right corner", "Bottom-right corner", "Bottom-left corner"];
const HANDLE_PX = 28; // 44px touch target once the invisible padding is added

interface Props {
  /** Full-resolution source. Coordinates below are in this image's pixel space. */
  source: ImageBitmap;
  value: Quad;
  onChange: (q: Quad) => void;
}

export function CornerEditor({ source, value, onChange }: Props) {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const wrapRef = useRef<HTMLDivElement>(null);
  const [dragging, setDragging] = useState<number | null>(null);
  const [loupeAt, setLoupeAt] = useState<Point | null>(null);

  // Displayed size vs. source size. All maths happens in source space.
  const scaleRef = useRef(1);

  const draw = useCallback(() => {
    const canvas = canvasRef.current;
    const wrap = wrapRef.current;
    if (!canvas || !wrap) return;

    const cssWidth = wrap.clientWidth;
    const scale = cssWidth / source.width;
    scaleRef.current = scale;

    const dpr = Math.min(window.devicePixelRatio || 1, 2);
    canvas.width = Math.round(cssWidth * dpr);
    canvas.height = Math.round(source.height * scale * dpr);
    canvas.style.width = `${cssWidth}px`;
    canvas.style.height = `${source.height * scale}px`;

    const ctx = canvas.getContext("2d")!;
    ctx.setTransform(dpr * scale, 0, 0, dpr * scale, 0, 0); // now drawing in source space
    ctx.drawImage(source, 0, 0);

    // Dim everything outside the quad so the crop reads at a glance.
    ctx.save();
    ctx.beginPath();
    ctx.rect(0, 0, source.width, source.height);
    ctx.moveTo(value[0].x, value[0].y);
    for (let i = 1; i < 4; i++) ctx.lineTo(value[i].x, value[i].y);
    ctx.closePath();
    ctx.fillStyle = "rgba(0,0,0,0.45)";
    ctx.fill("evenodd");
    ctx.restore();

    ctx.beginPath();
    ctx.moveTo(value[0].x, value[0].y);
    for (let i = 1; i < 4; i++) ctx.lineTo(value[i].x, value[i].y);
    ctx.closePath();
    ctx.lineWidth = 2 / scale;
    ctx.strokeStyle = "#38bdf8";
    ctx.stroke();
  }, [source, value]);

  useEffect(() => {
    draw();
    const ro = new ResizeObserver(draw);
    if (wrapRef.current) ro.observe(wrapRef.current);
    return () => ro.disconnect();
  }, [draw]);

  const toSourceSpace = (clientX: number, clientY: number): Point => {
    const rect = canvasRef.current!.getBoundingClientRect();
    const s = scaleRef.current;
    return {
      x: Math.max(0, Math.min(source.width, (clientX - rect.left) / s)),
      y: Math.max(0, Math.min(source.height, (clientY - rect.top) / s)),
    };
  };

  const commit = (index: number, p: Point) => {
    const next = value.map((c, i) => (i === index ? p : c)) as Quad;
    // Reject drags that fold the quad; the warp would produce garbage.
    if (!isConvexQuad(next)) return;
    onChange(next);
  };

  const onPointerDown = (index: number) => (e: React.PointerEvent) => {
    (e.target as Element).setPointerCapture(e.pointerId);
    setDragging(index);
    setLoupeAt(toSourceSpace(e.clientX, e.clientY));
  };

  const onPointerMove = (index: number) => (e: React.PointerEvent) => {
    if (dragging !== index) return;
    const p = toSourceSpace(e.clientX, e.clientY);
    setLoupeAt(p);
    commit(index, p);
  };

  const onPointerUp = () => {
    setDragging(null);
    setLoupeAt(null);
  };

  const onKeyDown = (index: number) => (e: React.KeyboardEvent) => {
    const step = e.shiftKey ? 10 : 1;
    const deltas: Record<string, Point> = {
      ArrowLeft: { x: -step, y: 0 },
      ArrowRight: { x: step, y: 0 },
      ArrowUp: { x: 0, y: -step },
      ArrowDown: { x: 0, y: step },
    };
    const d = deltas[e.key];
    if (!d) return;
    e.preventDefault();
    const c = value[index];
    commit(index, {
      x: Math.max(0, Math.min(source.width, c.x + d.x)),
      y: Math.max(0, Math.min(source.height, c.y + d.y)),
    });
  };

  const s = scaleRef.current;

  return (
    <div ref={wrapRef} className="relative w-full touch-none select-none">
      <canvas ref={canvasRef} className="block w-full rounded-md" />
      {value.map((c, i) => (
        <button
          key={i}
          type="button"
          aria-label={`${LABELS[i]}. Use arrow keys to adjust, shift plus arrow for larger steps.`}
          onPointerDown={onPointerDown(i)}
          onPointerMove={onPointerMove(i)}
          onPointerUp={onPointerUp}
          onPointerCancel={onPointerUp}
          onKeyDown={onKeyDown(i)}
          className="absolute grid place-items-center rounded-full border-2 border-sky-400 bg-sky-400/25 focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-2"
          style={{
            width: HANDLE_PX,
            height: HANDLE_PX,
            left: c.x * s - HANDLE_PX / 2,
            top: c.y * s - HANDLE_PX / 2,
            // Expand the hit area to 44px without growing the visual dot.
            padding: 8,
            margin: -8,
          }}
        />
      ))}
      {loupeAt && <Loupe source={source} at={loupeAt} displayScale={s} />}
    </div>
  );
}
```

```tsx
// src/components/tools/document-scanner/Loupe.tsx
"use client";

import { useEffect, useRef } from "react";
import type { Point } from "@/lib/scanner/types";

const SIZE = 108;
const ZOOM = 3;

/** Circular magnifier pinned above the finger so the corner stays visible. */
export function Loupe({
  source,
  at,
  displayScale,
}: {
  source: ImageBitmap;
  at: Point;
  displayScale: number;
}) {
  const ref = useRef<HTMLCanvasElement>(null);

  useEffect(() => {
    const canvas = ref.current;
    if (!canvas) return;
    const ctx = canvas.getContext("2d")!;
    const span = SIZE / ZOOM; // source pixels visible in the loupe
    ctx.clearRect(0, 0, SIZE, SIZE);
    ctx.save();
    ctx.beginPath();
    ctx.arc(SIZE / 2, SIZE / 2, SIZE / 2 - 2, 0, Math.PI * 2);
    ctx.clip();
    ctx.drawImage(source, at.x - span / 2, at.y - span / 2, span, span, 0, 0, SIZE, SIZE);
    ctx.restore();
    ctx.strokeStyle = "#38bdf8";
    ctx.lineWidth = 1;
    ctx.beginPath();
    ctx.moveTo(SIZE / 2 - 10, SIZE / 2);
    ctx.lineTo(SIZE / 2 + 10, SIZE / 2);
    ctx.moveTo(SIZE / 2, SIZE / 2 - 10);
    ctx.lineTo(SIZE / 2, SIZE / 2 + 10);
    ctx.stroke();
  }, [source, at]);

  return (
    <canvas
      ref={ref}
      width={SIZE}
      height={SIZE}
      aria-hidden
      className="pointer-events-none absolute rounded-full border-2 border-sky-400 bg-background shadow-lg"
      style={{
        left: Math.max(4, at.x * displayScale - SIZE / 2),
        top: Math.max(4, at.y * displayScale - SIZE - 36),
      }}
    />
  );
}
```

### [SCAN-04] Multi-page capture, reorder, per-page re-shoot, single PDF export

**Estimate:** 4h · **Depends on:** SCAN-03 · **Files:**
`src/components/tools/document-scanner/ScannerWidget.tsx`, `src/components/tools/document-scanner/PageStrip.tsx`, `src/lib/scanner/pdf.ts`, `src/lib/scanner/pdf.test.ts`

**Why** — Nobody scans one page. The unit of work is "the whole application form", and if the tool cannot produce one PDF with the pages in the right order it just moved the problem. Reorder and re-shoot exist because page 3 always comes out crooked.

**Implementation**

Encoding choice matters more than it looks: a bitonal page is dramatically smaller as PNG than as JPEG (flat runs compress; JPEG invents ringing around every stroke and then stores it).

```ts
// src/lib/scanner/pdf.ts
import { PDFDocument } from "pdf-lib";
import type { OutputMode } from "./types";

export interface ScannedPage {
  id: string;
  bitmap: ImageBitmap;
  mode: OutputMode;
}

async function encode(bitmap: ImageBitmap, mode: OutputMode): Promise<{ bytes: Uint8Array; png: boolean }> {
  const canvas = new OffscreenCanvas(bitmap.width, bitmap.height);
  canvas.getContext("2d")!.drawImage(bitmap, 0, 0);
  // Bitonal output is flat black-and-white: PNG's run-length + deflate beats
  // JPEG badly here, and JPEG adds ringing around every glyph.
  const png = mode === "bw";
  const blob = await canvas.convertToBlob(
    png ? { type: "image/png" } : { type: "image/jpeg", quality: 0.82 },
  );
  return { bytes: new Uint8Array(await blob.arrayBuffer()), png };
}

/** A4 at 72pt/inch, the PDF user-space unit. */
const A4 = { width: 595.28, height: 841.89 };

export async function pagesToPdf(pages: ScannedPage[], title: string): Promise<Blob> {
  if (pages.length === 0) throw new Error("No pages to export");

  const doc = await PDFDocument.create();
  doc.setTitle(title);
  doc.setProducer("kavithakanchana.me/tools/document-scanner");
  doc.setCreationDate(new Date());

  for (const page of pages) {
    const { bytes, png } = await encode(page.bitmap, page.mode);
    const image = png ? await doc.embedPng(bytes) : await doc.embedJpg(bytes);

    // Portrait or landscape A4 depending on the page's own aspect, then
    // letterbox the image inside it so nothing is stretched.
    const landscape = image.width > image.height;
    const pw = landscape ? A4.height : A4.width;
    const ph = landscape ? A4.width : A4.height;
    const pdfPage = doc.addPage([pw, ph]);

    const fit = Math.min(pw / image.width, ph / image.height);
    const w = image.width * fit;
    const h = image.height * fit;
    pdfPage.drawImage(image, { x: (pw - w) / 2, y: (ph - h) / 2, width: w, height: h });
  }

  return new Blob([await doc.save()], { type: "application/pdf" });
}
```

Page state in the widget — reorder via explicit buttons rather than drag-and-drop. Buttons are keyboard-accessible for free, work on touch without a gesture library, and cost 20 minutes instead of 3 hours.

```tsx
"use client";

import type { ScannedPage } from "@/lib/scanner/pdf";

export function movePage(pages: ScannedPage[], from: number, to: number): ScannedPage[] {
  if (to < 0 || to >= pages.length) return pages;
  const next = [...pages];
  const [item] = next.splice(from, 1);
  next.splice(to, 0, item);
  return next;
}

export function removePage(pages: ScannedPage[], id: string): ScannedPage[] {
  const target = pages.find((p) => p.id === id);
  target?.bitmap.close(); // ImageBitmap holds GPU/heap memory until closed
  return pages.filter((p) => p.id !== id);
}

export function replacePage(pages: ScannedPage[], id: string, next: ScannedPage): ScannedPage[] {
  return pages.map((p) => {
    if (p.id !== id) return p;
    p.bitmap.close();
    return next;
  });
}
```

### [SPEC-01] The spec schema, the build-time validator, and the `never` check that makes it safe to extend

**Estimate:** 3h · **Depends on:** — · **Files:**
`src/lib/specs/types.ts`, `src/lib/specs/validate.ts`, `src/lib/specs/index.ts`, `src/lib/specs/validate.test.ts`, `src/lib/tools/validate.ts` (reserved slugs)

**Why** — The registry has to drive two consumers pulling in opposite directions: the **resizer**, which needs a target ("make it 413×531 under 100 KB"), and the **validator**, which needs a predicate ("is it 413×531 and under 100 KB?"). Model it once as a list of discriminated constraints, and both fall out — the resizer projects constraints into a preset, the validator folds them into a report. Model it as loose fields on a flat object and you will end up with two divergent sources of truth within a month.

The `never` exhaustiveness check is the load-bearing bit: adding a new constraint kind without writing its checker becomes a **compile error**, not a silently-skipped check. Since Sprint 0 removed `ignoreBuildErrors`, that means it fails the build.

**Implementation**

```ts
// src/lib/specs/types.ts
export type ImageFormat = "jpeg" | "png" | "webp" | "pdf";

  | { mode: "range"; widthPx: [number, number]; heightPx: [number, number] }
  /** Physical size the authority states; we derive the pixel target from dpi. */
  | { mode: "print"; widthMm: number; heightMm: number; dpi: number };

export type Constraint =
  | { kind: "format"; allow: ImageFormat[] }
  | { kind: "dimensions"; rule: DimensionRule }
  | { kind: "fileSize"; minBytes?: number; maxBytes: number }
  | { kind: "aspectRatio"; ratio: number; tolerance: number }
  | { kind: "colorMode"; mode: ColorMode }
  /** sRGB target for the background, compared over a border ring in CIELAB. */
  | { kind: "background"; rgb: [number, number, number]; maxDeltaE: number }
  /** Chin-to-crown height as a fraction of image height. Needs face detection. */
  | { kind: "headHeightRatio"; min: number; max: number }
  | { kind: "pageCount"; max: number };

export type SpecStatus = "draft" | "verified";

export interface SpecSource {
  /** Primary source only: the authority's own page or PDF. Never a blog. */

  reviewIntervalDays: number;
```

```ts
// src/lib/specs/validate.ts
import type { UploadSpec, Constraint } from "./types";

const SLUG = /^[a-z0-9]+(?:-[a-z0-9]+)*$/;
const ISO_DATE = /^\d{4}-\d{2}-\d{2}$/;

/** Anti-content-farm cap, mirroring TOOLS.length > 30 in the tools registry. */
export const MAX_SPECS = 40;
export const MAX_PUBLISHED_SPEC_PAGES = 20;

function words(s: string): string[] {
  return s.toLowerCase().match(/[a-z0-9']+/g) ?? [];
}

/** Character trigram Jaccard similarity — catches templated submissionNotes. */
export function trigramSimilarity(a: string, b: string): number {
  const grams = (s: string) => {
    const t = s.toLowerCase().replace(/\s+/g, " ");
    const set = new Set<string>();
    for (let i = 0; i + 3 <= t.length; i++) set.add(t.slice(i, i + 3));
    return set;
  };
  const A = grams(a);
  const B = grams(b);
  if (A.size === 0 || B.size === 0) return 0;
  let inter = 0;
  A.forEach((g) => {
    if (B.has(g)) inter++;
  });
  return inter / (A.size + B.size - inter);
}

function assertConstraint(specId: string, c: Constraint): void {
  const fail = (m: string) => {
    throw new Error(`[specs] ${specId}: ${m}`);
  };
  switch (c.kind) {
    case "format":
      if (c.allow.length === 0) fail("format constraint allows nothing");
      return;
    case "dimensions":
      if (c.rule.mode === "exact") {
        if (c.rule.widthPx <= 0 || c.rule.heightPx <= 0) fail("non-positive exact dimensions");
      } else if (c.rule.mode === "range") {
        if (c.rule.widthPx[0] > c.rule.widthPx[1]) fail("inverted width range");
        if (c.rule.heightPx[0] > c.rule.heightPx[1]) fail("inverted height range");
      } else if (c.rule.dpi < 72) {
        fail("print rule with dpi below 72 — did the source really say that?");
      }
      return;
    case "fileSize":
      if (c.maxBytes <= 0) fail("maxBytes must be positive");
      if (c.minBytes !== undefined && c.minBytes >= c.maxBytes) fail("minBytes >= maxBytes");
      return;
    case "aspectRatio":
      if (c.ratio <= 0 || c.tolerance < 0) fail("bad aspect ratio");
      return;
    case "colorMode":
      return;
    case "background":
      if (c.rgb.some((v) => v < 0 || v > 255)) fail("rgb out of range");
      if (c.maxDeltaE <= 0) fail("maxDeltaE must be positive");
      return;
    case "headHeightRatio":
      if (!(c.min > 0 && c.max <= 1 && c.min < c.max)) fail("headHeightRatio out of bounds");
      return;
    case "pageCount":
      if (c.max < 1) fail("pageCount.max < 1");
      return;
    default: {
      // Add a Constraint variant without a rule here and the build stops.
      const exhaustive: never = c;
      throw new Error(`[specs] unhandled constraint: ${JSON.stringify(exhaustive)}`);
    }
  }
}

export function validateSpecs(specs: UploadSpec[]): void {
  if (specs.length > MAX_SPECS) {
    throw new Error(
      `[specs] ${specs.length} specs exceeds MAX_SPECS=${MAX_SPECS}. Raising this is a policy decision, not a data edit.`,
    );
  }

  const seen = new Set<string>();
  for (const s of specs) {
    if (!SLUG.test(s.id)) throw new Error(`[specs] bad id: "${s.id}"`);
    if (seen.has(s.id)) throw new Error(`[specs] duplicate id: "${s.id}"`);
    seen.add(s.id);

    if (s.constraints.length === 0) throw new Error(`[specs] ${s.id}: no constraints`);
    s.constraints.forEach((c) => assertConstraint(s.id, c));

    if (!ISO_DATE.test(s.source.verifiedOn)) {
      throw new Error(`[specs] ${s.id}: verifiedOn must be YYYY-MM-DD`);
    }
    if (Number.isNaN(Date.parse(s.source.verifiedOn))) {
      throw new Error(`[specs] ${s.id}: unparseable verifiedOn`);
    }
    if (!/^https:\/\//.test(s.source.url)) {
      throw new Error(`[specs] ${s.id}: source.url must be https and point at the authority`);
    }
    if (s.status === "verified" && !s.source.archivedUrl) {
      throw new Error(`[specs] ${s.id}: verified specs need a Wayback snapshot in source.archivedUrl`);
    }
    if (s.submissionNotes && words(s.submissionNotes).length < 150) {
      throw new Error(
        `[specs] ${s.id}: submissionNotes is ${words(s.submissionNotes).length} words; needs 150+ or omit it (spec stays page-less).`,
      );
    }
  }

  // Templated prose check: two specs must not read like the same paragraph
  // with the numbers swapped.
  const withNotes = specs.filter((s) => s.submissionNotes);
  for (let i = 0; i < withNotes.length; i++) {
    for (let j = i + 1; j < withNotes.length; j++) {
      const sim = trigramSimilarity(withNotes[i].submissionNotes!, withNotes[j].submissionNotes!);
      if (sim > 0.6) {
        throw new Error(
          `[specs] ${withNotes[i].id} and ${withNotes[j].id} submissionNotes are ${(sim * 100).toFixed(0)}% similar. Write real copy or drop one page.`,
        );
      }
    }
  }

  const published = specs.filter(isPublishable);
  if (published.length > MAX_PUBLISHED_SPEC_PAGES) {
    throw new Error(
      `[specs] ${published.length} publishable spec pages exceeds MAX_PUBLISHED_SPEC_PAGES=${MAX_PUBLISHED_SPEC_PAGES}.`,
    );
  }
}

/** The publication gate. See SPEC-05 for the reasoning. */
export function isPublishable(s: UploadSpec): boolean {
  return (
    s.status === "verified" &&
    !!s.submissionNotes &&
    words(s.submissionNotes).length >= 150 &&
    s.constraints.some(
      (c) => c.kind === "dimensions" || c.kind === "fileSize" || c.kind === "headHeightRatio",
    )
  );
}
```

### [SPEC-02] Seed the registry: transcription protocol + the first entries

**Estimate:** 4h · **Depends on:** SPEC-01 · **Files:**
`src/lib/specs/data/lk.ts`, `src/lib/specs/data/intl.ts`, `docs/spec-sourcing.md`

**Why** — The registry's entire value is that the numbers are right and the date is honest. A wrong constraint is worse than a missing one: someone follows it, their application is rejected, and the tool that was supposed to help caused the harm. So the process is the deliverable here, and the data follows the process.

**The rule, non-negotiable:** *do not commit a spec you have not personally opened the primary source for.* Everything starts life as `status: "draft"`, which means it is usable in the validator's dropdown with a visible "unverified" badge but generates **no page** and appears in **no sitemap**.

**Transcription protocol** (`docs/spec-sourcing.md`, and repeated as the PR checklist):

1. Find the authority's own artifact — the instruction PDF, the "guidelines" page, or the upload form itself with its inline error text. A blog, a YouTube tutorial, and a Facebook group are not sources.
2. Save a Wayback snapshot (`https://web.archive.org/save/<url>`) and paste the resulting permalink into `source.archivedUrl`. Government sites reorganize with no redirects; the snapshot is what makes `verifiedOn` auditable later.
3. Transcribe only what the source **states**. If it says "passport size" with no pixels, that is not a dimension constraint — it stays out, and the ambiguity goes in `source.note`.
4. Where the source states physical size + dpi, use `mode: "print"`. **Browsers do not reliably expose a file's DPI**, so the engine derives the pixel target from mm × dpi and checks pixels. A source that says only "600 dpi" with no physical size cannot be checked; that spec stays `draft`.
5. If the upload form is reachable, test it: upload a deliberately wrong file and record the exact rejection message in `source.note`. The error text is often stricter and more specific than the published guidance.
6. Set `status: "verified"` only after 1–5 are done, in the same commit, with the source PDF's title in `source.label`.

`lk-doe-exam-photo`, `lk-doe-exam-signature`, `lk-ugc-application-photo`, `lk-slbfe-registration-photo`, `lk-driving-licence-photo`, `lk-nic-photo`, plus `us-dv-lottery-photo` and `schengen-visa-photo`.

```ts
export interface ResizerPreset {

  heightPx?: number;
  maxBytes?: number;
  format?: "jpeg" | "png" | "webp";
  backgroundHex?: string;
  label: string;

const MM_PER_INCH = 25.4;

export function toResizerPreset(spec: UploadSpec): ResizerPreset {
  const preset: ResizerPreset = { label: `${spec.authority.name} — ${spec.name}` };

  for (const c of spec.constraints as Constraint[]) {
    if (c.kind === "dimensions") {
      if (c.rule.mode === "exact") {
        preset.widthPx = c.rule.widthPx;
        preset.heightPx = c.rule.heightPx;
      } else if (c.rule.mode === "range") {
        // Aim at the middle of the accepted range, not an edge.
        preset.widthPx = Math.round((c.rule.widthPx[0] + c.rule.widthPx[1]) / 2);
        preset.heightPx = Math.round((c.rule.heightPx[0] + c.rule.heightPx[1]) / 2);
      } else {
        preset.widthPx = Math.round((c.rule.widthMm / MM_PER_INCH) * c.rule.dpi);
        preset.heightPx = Math.round((c.rule.heightMm / MM_PER_INCH) * c.rule.dpi);
      }
    }
    if (c.kind === "fileSize") preset.maxBytes = c.maxBytes;
    if (c.kind === "format" && c.allow[0] !== "pdf") preset.format = c.allow[0] as "jpeg" | "png" | "webp";
    if (c.kind === "background") {
      preset.backgroundHex =
        "#" + c.rgb.map((v) => v.toString(16).padStart(2, "0")).join("");
    }
  }
  return preset;
}
```

### [SPEC-03] The validation engine: file probe → per-constraint report

**Estimate:** 4h · **Depends on:** SPEC-01, SPEC-02 · **Files:**
`src/lib/specs/probe.ts`, `src/lib/specs/engine.ts`, `src/lib/specs/color.ts`, `src/lib/specs/engine.test.ts`

**Why** — Everything the user needs to know is "does my file pass, and if not, exactly which rule did it break." Two design decisions carry the weight. First, **three states, not two**: `pass`, `fail`, `unknown`. A checker that cannot run yet (head-height needs face detection, arriving in Sprint 5) must say so rather than pass silently or fail wrongly. Second, **sniff the format from magic bytes**, never the extension — half the "JPEG" files people upload are PNGs their phone renamed, which is precisely why the government portal rejected them.

**Implementation**

```ts
// src/lib/specs/probe.ts
import { PDFDocument } from "pdf-lib";
import type { ColorMode } from "./types";

export interface FileProbe {
  bytes: number;
  /** From magic bytes, not from file.type or the extension. */
  mime: "image/jpeg" | "image/png" | "image/webp" | "application/pdf" | "unknown";
  widthPx?: number;
  heightPx?: number;
  colorMode?: ColorMode;
  /** Median sRGB of a border ring, used for background checks. */
  borderRgb?: [number, number, number];
  pageCount?: number;
}

function sniff(head: Uint8Array): FileProbe["mime"] {
  const ascii = (o: number, n: number) =>
    String.fromCharCode(...Array.from(head.slice(o, o + n)));
  if (head[0] === 0xff && head[1] === 0xd8 && head[2] === 0xff) return "image/jpeg";
  if (head[0] === 0x89 && ascii(1, 3) === "PNG") return "image/png";
  if (ascii(0, 4) === "RIFF" && ascii(8, 4) === "WEBP") return "image/webp";
  if (ascii(0, 4) === "%PDF") return "application/pdf";
  return "unknown";
}

function analysePixels(data: Uint8ClampedArray, w: number, h: number) {
  let anyChroma = false;
  let anyMidtone = false;
  const step = Math.max(1, Math.floor((w * h) / 40000)); // cap at ~40k samples
  for (let i = 0; i < w * h; i += step) {
    const p = i * 4;
    const r = data[p];
    const g = data[p + 1];
    const b = data[p + 2];
    if (Math.abs(r - g) > 2 || Math.abs(g - b) > 2) anyChroma = true;
    const lum = 0.299 * r + 0.587 * g + 0.114 * b;
    if (lum > 24 && lum < 231) anyMidtone = true;
    if (anyChroma && anyMidtone) break;
  }
  const colorMode: ColorMode = anyChroma ? "color" : anyMidtone ? "grayscale" : "bitonal";

  // Border ring: outermost 3% on each edge, median per channel.
  const band = Math.max(1, Math.round(Math.min(w, h) * 0.03));
  const rs: number[] = [];
  const gs: number[] = [];
  const bs: number[] = [];
  const push = (x: number, y: number) => {
    const p = (y * w + x) * 4;
    rs.push(data[p]);
    gs.push(data[p + 1]);
    bs.push(data[p + 2]);
  };
  for (let x = 0; x < w; x += 2) {
    for (let y = 0; y < band; y++) {
      push(x, y);
      push(x, h - 1 - y);
    }
  }
  for (let y = band; y < h - band; y += 2) {
    for (let x = 0; x < band; x++) {
      push(x, y);
      push(w - 1 - x, y);
    }
  }
  const median = (a: number[]) => a.sort((p, q) => p - q)[Math.floor(a.length / 2)] ?? 255;
  return { colorMode, borderRgb: [median(rs), median(gs), median(bs)] as [number, number, number] };
}

export async function probeFile(file: File): Promise<FileProbe> {
  const head = new Uint8Array(await file.slice(0, 16).arrayBuffer());
  const mime = sniff(head);
  const probe: FileProbe = { bytes: file.size, mime };

  if (mime === "application/pdf") {
    const doc = await PDFDocument.load(await file.arrayBuffer(), { updateMetadata: false });
    probe.pageCount = doc.getPageCount();
    return probe;
  }
  if (mime === "unknown") return probe;

  const bitmap = await createImageBitmap(file);
  probe.widthPx = bitmap.width;
  probe.heightPx = bitmap.height;

  const canvas = document.createElement("canvas");
  canvas.width = bitmap.width;
  canvas.height = bitmap.height;
  const ctx = canvas.getContext("2d", { willReadFrequently: true })!;
  ctx.drawImage(bitmap, 0, 0);
  const { data } = ctx.getImageData(0, 0, bitmap.width, bitmap.height);
  const analysed = analysePixels(data, bitmap.width, bitmap.height);
  probe.colorMode = analysed.colorMode;
  probe.borderRgb = analysed.borderRgb;
  bitmap.close();
  return probe;
}
```

```ts
// src/lib/specs/color.ts
/** sRGB -> CIELAB (D65), then CIE76 deltaE. Good enough for "is this white?". */
function srgbToLinear(c: number): number {
  const v = c / 255;
  return v <= 0.04045 ? v / 12.92 : Math.pow((v + 0.055) / 1.055, 2.4);
}

function rgbToLab([r, g, b]: [number, number, number]): [number, number, number] {
  const R = srgbToLinear(r);
  const G = srgbToLinear(g);
  const B = srgbToLinear(b);
  let x = (R * 0.4124 + G * 0.3576 + B * 0.1805) / 0.95047;
  let y = R * 0.2126 + G * 0.7152 + B * 0.0722;
  let z = (R * 0.0193 + G * 0.1192 + B * 0.9505) / 1.08883;
  const f = (t: number) => (t > 0.008856 ? Math.cbrt(t) : 7.787 * t + 16 / 116);
  x = f(x);
  y = f(y);
  z = f(z);
  return [116 * y - 16, 500 * (x - y), 200 * (y - z)];
}

export function deltaE(a: [number, number, number], b: [number, number, number]): number {
  const [l1, a1, b1] = rgbToLab(a);
  const [l2, a2, b2] = rgbToLab(b);
  return Math.hypot(l1 - l2, a1 - a2, b1 - b2);
}
```

```ts
// src/lib/specs/engine.ts
import type { Constraint, UploadSpec, ImageFormat } from "./types";
import type { FileProbe } from "./probe";
import { deltaE } from "./color";

export type CheckStatus = "pass" | "fail" | "unknown";

export interface FixAction {
  label: string;
  href: string;
}

export interface CheckResult {
  kind: Constraint["kind"];
  status: CheckStatus;
  expected: string;
  actual: string;
  fix?: FixAction;
}

export interface SpecReport {
  specId: string;
  fileName: string;
  results: CheckResult[];
  /** "incomplete" when nothing failed but something could not be checked. */
  verdict: "pass" | "fail" | "incomplete";
}

const MM_PER_INCH = 25.4;
const MIME_TO_FORMAT: Record<string, ImageFormat> = {
  "image/jpeg": "jpeg",
  "image/png": "png",
  "image/webp": "webp",
  "application/pdf": "pdf",
};

const kb = (n: number) => `${Math.round(n / 1024)} KB`;

function fixFor(c: Constraint, spec: UploadSpec): FixAction | undefined {
  const q = `?preset=spec:${spec.id}`;
  switch (c.kind) {
    case "dimensions":
    case "aspectRatio":
      return { label: "Resize to the required size", href: `/tools/image-resizer${q}` };
    case "fileSize":
      return { label: "Compress under the size limit", href: `/tools/image-compressor${q}` };
    case "format":
      return { label: `Convert to ${c.allow[0].toUpperCase()}`, href: `/tools/image-converter${q}` };
    case "colorMode":
      return { label: "Change color mode", href: `/tools/image-converter${q}` };
    case "background":
      return { label: "Replace the background", href: `/tools/background-remover${q}` };
    case "pageCount":
      return { label: "Split or merge pages", href: `/tools/pdf-split${q}` };
    case "headHeightRatio":
      return undefined; // passport crop tool lands in Sprint 5
    default: {
      const exhaustive: never = c;
      return exhaustive;
    }
  }
}

function checkOne(c: Constraint, p: FileProbe, spec: UploadSpec): CheckResult {
  const base = { kind: c.kind, fix: undefined as FixAction | undefined };
  const fail = (expected: string, actual: string): CheckResult => ({
    ...base,
    status: "fail",
    expected,
    actual,
    fix: fixFor(c, spec),
  });
  const pass = (expected: string, actual: string): CheckResult => ({
    ...base,
    status: "pass",
    expected,
    actual,
  });
  const unknown = (expected: string, why: string): CheckResult => ({
    ...base,
    status: "unknown",
    expected,
    actual: why,
  });

  switch (c.kind) {
    case "format": {
      const actual = MIME_TO_FORMAT[p.mime];
      const expected = c.allow.map((f) => f.toUpperCase()).join(" or ");
      if (!actual) return fail(expected, "Unrecognized file type");
      return c.allow.includes(actual)
        ? pass(expected, actual.toUpperCase())
        : fail(expected, actual.toUpperCase());
    }
    case "dimensions": {
      if (p.widthPx === undefined || p.heightPx === undefined) {
        return unknown("pixel dimensions", "Not an image");
      }
      const actual = `${p.widthPx} x ${p.heightPx} px`;
      if (c.rule.mode === "exact") {
        const expected = `${c.rule.widthPx} x ${c.rule.heightPx} px`;
        return p.widthPx === c.rule.widthPx && p.heightPx === c.rule.heightPx
          ? pass(expected, actual)
          : fail(expected, actual);
      }
      if (c.rule.mode === "range") {
        const [wMin, wMax] = c.rule.widthPx;
        const [hMin, hMax] = c.rule.heightPx;
        const expected = `${wMin}-${wMax} x ${hMin}-${hMax} px`;
        const ok = p.widthPx >= wMin && p.widthPx <= wMax && p.heightPx >= hMin && p.heightPx <= hMax;
        return ok ? pass(expected, actual) : fail(expected, actual);
      }
      // print: derive pixels, because browsers do not expose real DPI.
      const w = Math.round((c.rule.widthMm / MM_PER_INCH) * c.rule.dpi);
      const h = Math.round((c.rule.heightMm / MM_PER_INCH) * c.rule.dpi);
      const expected = `${c.rule.widthMm} x ${c.rule.heightMm} mm at ${c.rule.dpi} dpi (${w} x ${h} px)`;
      const tol = 0.02;
      const ok =
        Math.abs(p.widthPx - w) <= w * tol && Math.abs(p.heightPx - h) <= h * tol;
      return ok ? pass(expected, actual) : fail(expected, actual);
    }
    case "fileSize": {
      const expected = c.minBytes
        ? `${kb(c.minBytes)}-${kb(c.maxBytes)}`
        : `at most ${kb(c.maxBytes)}`;
      const actual = kb(p.bytes);
      const ok = p.bytes <= c.maxBytes && (c.minBytes === undefined || p.bytes >= c.minBytes);
      return ok ? pass(expected, actual) : fail(expected, actual);
    }
    case "aspectRatio": {
      if (!p.widthPx || !p.heightPx) return unknown(`${c.ratio}:1`, "Not an image");
      const actualRatio = p.widthPx / p.heightPx;
      const expected = `${c.ratio.toFixed(3)} +/- ${c.tolerance}`;
      const actual = actualRatio.toFixed(3);
      return Math.abs(actualRatio - c.ratio) <= c.tolerance
        ? pass(expected, actual)
        : fail(expected, actual);
    }
    case "colorMode": {
      if (!p.colorMode) return unknown(c.mode, "Not an image");
      return p.colorMode === c.mode ? pass(c.mode, p.colorMode) : fail(c.mode, p.colorMode);
    }
    case "background": {
      if (!p.borderRgb) return unknown("plain background", "Not an image");
      const d = deltaE(p.borderRgb, c.rgb);
      const expected = `rgb(${c.rgb.join(", ")}) within deltaE ${c.maxDeltaE}`;
      const actual = `rgb(${p.borderRgb.join(", ")}), deltaE ${d.toFixed(1)}`;
      return d <= c.maxDeltaE ? pass(expected, actual) : fail(expected, actual);
    }
    case "headHeightRatio":
      return unknown(
        `head height ${Math.round(c.min * 100)}-${Math.round(c.max * 100)}% of image height`,
        "Not checked automatically yet — measure by eye against the guide overlay",
      );
    case "pageCount": {
      if (p.pageCount === undefined) return unknown(`at most ${c.max} pages`, "Not a PDF");
      return p.pageCount <= c.max
        ? pass(`at most ${c.max} pages`, `${p.pageCount}`)
        : fail(`at most ${c.max} pages`, `${p.pageCount}`);
    }
    default: {
      const exhaustive: never = c;
      throw new Error(`Unhandled constraint: ${JSON.stringify(exhaustive)}`);
    }
  }
}

export function checkAgainstSpec(
  spec: UploadSpec,
  probe: FileProbe,
  fileName: string,
): SpecReport {
  const results = spec.constraints.map((c) => checkOne(c, probe, spec));
  const verdict = results.some((r) => r.status === "fail")
    ? "fail"
    : results.some((r) => r.status === "unknown")
      ? "incomplete"
      : "pass";
  return { specId: spec.id, fileName, results, verdict };
}
```

```ts
import { toResizerPreset, type ResizerPreset } from "@/lib/specs/preset";

/**
 * Contract: `?preset=spec:<id>`. Any file tool can opt in with one line.
 * Returns null when absent or when the id is unknown, so tools degrade to
 * their own defaults rather than throwing.
 */
export function useSpecPreset(): (ResizerPreset & { specId: string }) | null {
  const params = useSearchParams();
  const raw = params.get("preset");
  return useMemo(() => {
    if (!raw?.startsWith("spec:")) return null;
    const spec = getSpec(raw.slice("spec:".length));
    if (!spec) return null;
    return { ...toResizerPreset(spec), specId: spec.id };
  }, [raw]);
}
```

### [SPEC-05] Per-spec pages that are not programmatic spam

**Estimate:** 2h · **Depends on:** SPEC-02, SPEC-04 · **Files:**
`src/app/(tools)/tools/spec/[spec]/page.tsx`, `src/lib/specs/jsonld.ts`, `src/app/sitemap.ts`

**Why** — A registry of upload specs is exactly the input that tempts people into generating 400 near-identical pages. That is the failure mode to design against, not the opportunity to chase. The bottleneck is indexation, not page count: thin pages don't just fail to rank, they dilute the crawl budget of the pages that would have.

**The concrete line, enforced in code:**

> A spec earns its own URL only when **all four** hold: (1) `status: "verified"` against a primary source Kavitha personally opened, with a Wayback permalink; (2) it carries at least one constraint that is *not guessable from the document's name* — a specific pixel size, byte cap, or ratio; (3) it has ≥ 150 words of hand-written `submissionNotes` describing what actually goes wrong when people submit to *this* system, unique against every other spec at < 0.6 trigram similarity; and (4) a working tool, preset-loaded from this spec, sits above the fold. Fail any one and the spec **stays in the registry** — usable in the validator dropdown, linked from the hub — but renders **no URL**, appears in **no sitemap**, and is excluded from `generateStaticParams`. Ceiling: 20 published spec pages. Raising it is a policy edit with a written justification, not a data change.

Conditions 1–3 are already enforced by `isPublishable` and `validateSpecs` in SPEC-01. This ticket wires them to the routing layer so the rule is structural, not aspirational.

**Implementation**

```ts
import type { UploadSpec } from "./types";
import { DATA } from "@/data/resume";

export const HARD_STALE_DAYS = 365;

export function ageInDays(spec: UploadSpec): number {
  return Math.floor((Date.now() - Date.parse(spec.source.verifiedOn)) / 86_400_000);
}

export function isStale(spec: UploadSpec): boolean {
  return ageInDays(spec) > HARD_STALE_DAYS;
}

        url,
        dateModified: spec.source.verifiedOn,
        author: { "@id": `${DATA.url}/#person` },
        isPartOf: { "@id": `${DATA.url}/#website` },
        mainEntityOfPage: url,
        citation: spec.source.archivedUrl ?? spec.source.url,
        mentions: { "@id": `${DATA.url}/tools/upload-checker#app` },

          { "@type": "ListItem", position: 2, name: "Upload specs", item: `${DATA.url}/tools/upload-checker` },
          { "@type": "ListItem", position: 3, name: spec.name, item: url },

      },

  };
```

### [SPEC-06] Freshness watchdog

**Estimate:** 1h · **Depends on:** SPEC-05 · **Files:**
`scripts/check-spec-freshness.mjs`, `.github/workflows/spec-freshness.yml`

**Why** — `verifiedOn` is worthless if nothing forces it forward. A monthly job that files one issue with a list is the cheapest mechanism that survives a busy quarter. It must not be a build gate — a failing deploy at 3am because a date crossed a threshold is how you learn to delete the check.

**Implementation**

```js
// scripts/check-spec-freshness.mjs — run with: node --experimental-strip-types
import { SPECS } from "../src/lib/specs/index.ts";

const now = Date.now();
const due = SPECS.map((s) => {
  const age = Math.floor((now - Date.parse(s.source.verifiedOn)) / 86_400_000);
  return { ...s, age };
})
  .filter((s) => s.age > s.reviewIntervalDays)
  .sort((a, b) => b.age - a.age);

if (due.length === 0) {
  console.log("All specs within their review interval.");
  process.exit(0);
}

const lines = due.map(
  (s) => `- [ ] \`${s.id}\` — ${s.age}d old (interval ${s.reviewIntervalDays}d) — ${s.source.url}`,
);
console.log(
  `${due.length} spec(s) are due for re-verification.\n\n${lines.join("\n")}\n\n` +
    `Protocol: docs/spec-sourcing.md. Re-open the source, re-snapshot to Wayback, ` +
    `update verifiedOn even if nothing changed.`,
);
process.exit(1);
```

The workflow runs on the 1st of each month, and on failure creates or updates a single issue titled `Spec re-verification due` with the script output as the body (`gh issue list --search` then `gh issue create`/`gh issue comment`) — one issue, not one per spec.

**Acceptance criteria**

- [ ] `node scripts/check-spec-freshness.mjs` exits 0 today and exits 1 with a checklist after backdating one `verifiedOn`.
- [ ] The workflow runs on `workflow_dispatch` and produces a single GitHub issue with the checklist.
- [ ] The job is **not** part of the Vercel build or the PR CI gate.
